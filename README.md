# Список заблокированных сайтов

> **Важно.** Домен `ooni.io` заблокирован в РФ — для запуска генератора из России нужен VPN или прокси.

Список доменов, заблокированных в России, на основе данных [OONI](https://ooni.org/).

База заблокированных сайтов перестала публиковаться Роскомнадзором в общем доступе, а в будущем может перестать поставляться даже операторам связи — возникла потребность в альтернативном источнике.

## Методика

Данные OONI агрегируются через официальное API (`api.ooni.io`):

- отбрасываются некорректные домены (с подряд идущими точками);
- из повторяющихся доменов оставляется запись с наибольшим `measurement_count`;
- домен попадает в список, если `anomaly_count > ok_count` (аномалий больше, чем успешных подключений).

По умолчанию отбираются аномалии за последние 7 дней.

Список может использоваться проектами, пользующимися списком Роскомнадзора в качестве альтернативы (VPN-сервисы, браузерные расширения).

## Запуск

Требуется Python 3.13+. Управление зависимостями — через [uv](https://docs.astral.sh/uv/).

```bash
# установить зависимости в .venv
uv sync

# запустить генератор
uv run python3 generate.py
```

Альтернативно — через [devbox](https://www.jetify.com/devbox) (при наличии [direnv](https://direnv.net/)):

```bash
devbox run start
```

Результат — файл `domains.lst` в корне репозитория. Промежуточный `ooni_data.csv` удаляется по завершении.
